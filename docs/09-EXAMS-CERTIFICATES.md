# Examinations, Results & Certificates

## Exams
Faculty with permission can create exams and configure duration, total marks, pass marks, negative marking, availability window and attempt rules.

Initial online exam support prioritizes MCQ. The data model must remain extensible to descriptive/practical/manual-evaluation types later.

## Question Bank
Questions may be associated with course/module/topic, difficulty and reusable question banks. Faculty can create/manage questions according to permissions.

## Attempts
Track start/end, answers, score, status and rule snapshot. Do not trust client-side scoring for final results.

## Result
Automatic scoring for supported objective questions. Manual review workflow can be introduced for non-objective assessments.

## Certificates
Passing an exam can make the learner certificate-eligible. Faculty issues the certificate; issuance is not silently automatic without the required faculty action.

Certificate features:
- unique certificate number
- generated certificate file
- QR verification
- public verification page
- issue date and issuer
- revoke/reissue history

Registration/certificate numbering rules remain configurable until official formats are supplied.
